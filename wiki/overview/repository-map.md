# Repository Map

## Purpose

This page explains where project implementation and wiki artifacts live.

## Areas

- `src/` - React application source for the board UI and interaction logic.
- `raw/` - Immutable source material such as requirements, screenshots, research notes, and references.
- `wiki/` - LLM-maintained project knowledge, feature pages, engineering notes, decisions, research, and execution history.
- `index.md` - Human-readable catalog of wiki content.
- `log.md` - Append-only chronological history of project and wiki activity.
- `copilot.md` - Operating schema for how the LLM should maintain the repository and wiki.

## Current Notes

The repo does not yet contain imported raw sources. The first version focuses on application scaffolding plus wiki initialization.
