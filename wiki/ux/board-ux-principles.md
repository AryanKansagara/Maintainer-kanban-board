# Board UX Principles

## Principles

- Keep status lanes visually legible at a glance.
- Preserve direct manipulation for high-frequency actions.
- Favor inline editing over disruptive modal flows for the MVP.
- Make the board dense enough for work, but not visually flat.
- Keep task priority and assignee visible without crowding the card.

## Current UI Direction

The first version uses a dark operational workspace with strong lane separation, compact cards, and a fixed control sidebar for board-level actions.

## Follow-up

Test whether inline card editing conflicts with drag affordances on smaller screens.
