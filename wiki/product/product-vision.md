# Product Vision

## Goal

Build a Kanban board that feels operational and clear for day-to-day task movement, while taking selective inspiration from Azure DevOps Boards instead of cloning it wholesale.

## Product Direction

- Clear visual lanes for work state.
- Fast card editing without modal-heavy workflows.
- Direct manipulation through drag-and-drop.
- A structure that can later support persistence, filtering, richer metadata, and multi-board workflows.

## Scope for the First Version

- Board with multiple columns.
- Column creation and renaming.
- Card creation, editing, deletion, and drag movement.
- Card metadata fields for title, description, assignee, and priority.

## Deferred

- Backend persistence
- Authentication
- WIP limits
- Swimlanes
- Filtering and search
- Audit trail inside the product UI
