# Azure DevOps Reference

## Purpose

Track which ideas are being borrowed from Azure DevOps Boards and which are not.

## Borrowed Patterns

- Horizontal status lanes
- Work item movement by drag-and-drop
- Operational visibility of task state
- Board-first workflow organization

## Deliberate Differences in the MVP

- Simpler inline editing
- Lighter metadata model
- No enterprise workflow rules yet
- No team-scale backlog and sprint system yet
